SQL Anywhere // Comment Removal Diagnostics
==========================================

Run these commands in PowerShell from the DBObject_Masking repository directory.

1. Confirm the current directory and Git version:

Get-Location
git remote -v
git branch --show-current
git rev-parse --short HEAD

2. Confirm that // comment support exists:

Select-String migration_engine.py -Pattern "'//'"

Expected code:

if text[index:index + 2] in {'--', '//'}:

3. Confirm which migration_engine.py Python imports and test comment removal directly:

python -c "import migration_engine; print(getattr(migration_engine, '__file__')); sql='SELECT 1; // remove this comment'+chr(10)+'SELECT 2;'; print(repr(migration_engine._strip_sql_comments(sql)))"

Expected cleaned SQL:

'SELECT 1; \nSELECT 2;'

4. Check whether an older Python application process is still running:

Get-Process python,pythonw -ErrorAction SilentlyContinue | Select-Object Id,Path

Close the old application before starting it again.

5. Recreate the local virtual environment if required:

py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

6. Start the application explicitly from this checkout:

.\.venv\Scripts\python.exe launcher.py
