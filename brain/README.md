# Migration Brain

`lessons/` contains sanitized YAML lessons promoted from approved human
corrections. Complete unmasked procedures, reviewer identities, connection
details, paths, and project history remain only in the local SQLite database.

Lesson files are immutable and content-addressed. Commit reviewed lessons to
Git so other installations can discover the same migration knowledge. A lesson
is evidence and a retrieval reference; context-sensitive behavior should later
be promoted into a tested catalogue renderer before it is applied generally.
